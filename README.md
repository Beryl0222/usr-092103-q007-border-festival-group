# 边境节庆团组协同

面向中俄合唱交流、体育大会与口岸贸易活动的团组协同系统。境内外领队各自维护成员资料，
各方通过仓库约定的版本化领域事件交换变更，全部过程留痕可追溯。

## 运行

```bash
npm test     # 29 个契约与领域规则测试
npm run demo # 端到端演示：三个团组从登记到结算的完整一天
```

## 架构

追加式事件存储（`src/events.js`）是唯一事实来源：每个聚合一条单调递增的版本序列，
写入方可携带 `expected_version` 做乐观并发控制，冲突抛 `ConcurrencyError` 由调用方重试。
事件信封遵循 `contracts/domain.schema.json`（`src/validator.js` 校验）。

| 模块 | 职责 |
| --- | --- |
| `src/members.js` | 团组与成员：容量满后候补、退出留痕、候补按序转正、同名按身份标识消歧；语言需求、保险、紧急联系人由领队维护 |
| `src/eligibility.js` | 跨境资格只接受已登记的有权来源（按确认类型与项目范围授权）；事件只记录状态与来源引用，不含证件号 |
| `src/inventory.js` | 车辆/房间/席位统一为带容量资源；同一资源的预订落在同一版本序列上，并发下拒绝过期版本写入，容量校验兜底，绝不超售；多人共用预订即一条 hold 多人；占位超时自动失效 |
| `src/crossing.js` | 口岸分时通行；临时限流时按团队关系提出分批方案（团组不拆散，单团超容量时领队首批），只追加改期事件，不删除行程 |
| `src/contracts.js` | 合作合同按版本生效，判定责任时取变更时点已生效的最新版本 |
| `src/settlement.js` | 取消责任按变更时点与合同版本判定费率档位；活动结束后以实际到访（ATTENDANCE_RECORDED）为结算依据，取消费用并入 |
| `src/exports.js` | 最小化披露矩阵：合作方只拿履约所需字段，证件细节仅口岸有权渠道可见；每次导出登记接收方、用途与失效时间，过期导出拒绝使用 |
| `src/i18n.js` | 中俄双语词条，领队清单双语呈现 |
| `src/risk.js` | 调度员风险总览：资格/保险/紧急联系人缺口、候补、未分房未排车、口岸限流、导出临期，双语呈现 |

## 关键约定

- **事件版本交换变更**：所有变更以事件追加，聚合版本单调递增；`expected_version` 是并发写入的唯一防线。
- **敏感数据最小化**：证件号不进入任何事件载荷（成员更新事件只记录字段名）；导出按接收对象裁剪字段。
- **过程保留**：退出、转正、改期、释放、失效都是状态事件而非删除，任何时点可回放。
- **结算口径**：以实际到访人数 × 合同单价 + 按变更时点核定的取消费用。

## 资料结构

- `contracts/domain.schema.json`：领域事件公共信封与稳定枚举（23 种事件、10 种聚合）。
- `data/sample.json`：最小业务事件样例。
- `src/`：事件存储、领域服务与装配（`src/index.js` 的 `createSystem`）。
- `scripts/demo.js`：端到端演示场景。
- `tests/`：契约与领域规则测试。
